# Refund a tuition deposit

Use this procedure when an applicant withdraws before the term starts and asks for their deposit back.

## Before you start

Deposits are refundable for 30 days after payment. After that, the Bursar decides.

## Steps

1. Find the deposit in NetSuite by student ID.
2. Check the payment date against the 30-day window.
3. Create a refund against the original payment method.
4. Set the enrollment status in Salesforce to Withdrawn.

## Who to ask

| Question | Team |
| - | - |
| Refund amounts | Finance Systems |
| Enrollment status | Admissions Ops |
