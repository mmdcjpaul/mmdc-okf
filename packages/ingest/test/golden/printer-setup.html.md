# Set up the campus printer

Printers are on the **staff** network. You need your _badge number_.

## Steps

1. Open `Settings`, then Printers.
2. Add the printer named `CAMPUS-01`.
3. Print a test page.

## Supported paper

| Tray | Paper |
| - | - |
| 1 | A4 |
| 2 | Letter |

See [the printer list](https://intranet.example/it/printers).

Ask IT Support if it fails.
